# URDF Visualization Web System

An online system for URDF visualization, parameter editing, left-right mirroring, and classification checks for robotic hand URDF files. Built according to the PRD, currently at **Phase 1-1: Local Web Version**.

## Features (Phase 1-1)

- **Login Page**: Invite-code registration (invite codes generated by admins), username + password + confirm password, auto-logout after 3 hours of inactivity
- **Main Function Page**
  - **Section 1**: Left/right hand `.urdf` import; 2D joint node connection graph (auto-scaled by DOF, click nodes to see full joint/link names, active DOFs marked with `m`, non-standard names highlighted in red); DOF statistics at top (total/active/passive); left-right hand switching
  - **Section 2**: Left-right hand mirroring — **UI placeholder**, Phase 1-2 will integrate `urdf_mirror.py`
  - **Section 3**: Classification checks — **UI placeholder**, Phase 1-2 will integrate `urdf_parser_checker.py`
  - **Section 4**: Click joint nodes to view kinematic/dynamic parameter tables; "Confirm Changes" validates data types (errors highlighted in red, export blocked); "Export URDF" with progress bar, syncs updates to the server-side file
- **Admin Dashboard** (visible only to admins/super admins)
  - **Section 1**: Query active users and feature usage counts by year/month/day
  - **Section 2**: User search, grant/revoke admin, ban/restore, generate invite codes
  - **Section 3**: Ban users by name, "ban all users" (except super admin), upload standard naming table `standard_urdf_name.xlsx`
- **Roles & Permissions**: Super Admin (first account `admin`, permanent, cannot be demoted/disabled) > Admin > Regular User

## Tech Stack

- **Frontend**: Vue 3 (lightweight build-free version `static/vendor/vue.global.prod.js`, no bundling required)
- **Backend**: FastAPI + SQLAlchemy
- **Database**: Local SQLite (`data/app.db`); switch to MySQL on cloud by setting:
  `DATABASE_URL=mysql+pymysql://user:pass@host:3306/urdf_web?charset=utf8mb4`

## Standard Naming Table

Place `standard_urdf_name.xlsx` in the `data/` directory, or upload it via Admin Dashboard Section 3. All cell values in the sheet are treated as valid joint/link names; without it, Section 1 skips name validation and shows a hint.
